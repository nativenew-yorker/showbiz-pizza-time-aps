Supported input: stereo PCM16 WAV at 44.1 kHz or 48 kHz. No server upload is used. Large showtapes need a desktop-class browser and several hundred MB of free memory.

Audio note: movement/timing/container mapping follows the established converter logic. In the browser, 44.1→48 kHz program audio uses deterministic linear resampling and SHW audio uses a 320 kbps LAME browser encoder, so the audio bytes are not guaranteed byte-identical to desktop FFmpeg. The robot data is unaffected by this.
